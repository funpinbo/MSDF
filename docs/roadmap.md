# 로드맵

## 현재 상태

**설계 완료, 구현 시작 전 (0.0.0).** 저장소에는 패키지 뼈대, 예외 체계(`ms_dataflow/errors.py`), 예제 설정 파일, 건너뛰기로 표시된 테스트가 있습니다.
다른 문서의 코드와 명령은 아직 동작하지 않습니다.

## 방향

MSDF가 지키려는 것은 한 문장입니다.

> **서비스 사이 데이터 이동의 권한, 실패, 추적을 쉽게 하는 계층이지, 서비스 전체를 관리하는 시스템이 아니다.**

이 방향에서 나오는 원칙:

- **사용자가 외울 것을 줄인다.** 함수 다섯 개와 YAML 세 개가 전부여야 합니다. 데이터 ID, 큐, HTTP, 직렬화 포맷이 사용자 코드에 나오면 설계를 되돌립니다.
- **틀린 것은 실행 전에 막는다.** 런타임에 터지기보다 로딩할 때 파일, 줄, 원문, 이유, 고칠 방법을 함께 알려 줍니다.
- **각 부분은 책임 하나만 진다.** 데이터는 Resolver, 출처는 Artifact 테이블, 권한은 IAM, 순서는 Planner.
- **로컬에서 먼저 쓸 수 있게 한다.** 처음 버전은 한 머신, 한 사용자, SQLite를 전제로 합니다. 여러 머신으로 퍼지는 기능(인증 등)은 그 다음입니다.

## 구현 순서

앞 단계 위에 뒤 단계가 쌓이는 순서입니다.

| 단계 | 내용 | 끝나면 할 수 있는 것 |
| --- | --- | --- |
| 1 | ID 계산과 메타데이터 테이블 (SQLite) | 같은 입력에 항상 같은 ID가 나오는지 테스트 |
| 2 | `@service`, `@action` 데코레이터와 버전 계산 | 선언 오류를 로딩 때 잡음 |
| 3 | 코드 분석(Action 수집), DAG 로더, 로딩 검증 | `msdf`가 설정 파일 오류를 알려 줌 |
| 4 | Planner (필요한 단계만 고르기, 캐시 제외) | 무엇을 다시 계산할지 미리 확인 |
| 5 | 로컬 Resolver (파일, SQLite)와 `resolvers.yaml` | **프로세스 하나로 흐름 전체 실행**, 캐시 동작 확인 |
| 6 | Scheduler와 서비스 수신 서버 | 서비스를 각자 프로세스로 띄워 실행, 재시도와 배달 |
| 7 | `msdf up` CLI | 명령 하나로 엔진 기동 |
| 8 | IAM 규칙 검사 (`order`, `flow`, `delete`) | 권한 적용 |
| 9 | 삭제 요청과 보관 정책 (hot/cold) | 데이터 정리 |
| 10 | 웹 UI: DAG 보기, 실패 위치 표시, 이후 DAG 편집 | 화면으로 흐름 관리 |

1~5단계는 프로세스 하나로 돌려 볼 수 있어서, 서버를 만들기 전에 "같은 요청은 캐시된다", "로직을 바꾸면 그 단계부터 다시 계산한다"를 먼저 검증합니다.

## 아직 정하지 않은 것

구현하며 정할 항목입니다. 의견은 이슈로 남겨 주세요.

| 항목 | 현재 생각 |
| --- | --- |
| order 호출 형태 | `order()` 함수가 기본안. `@order` 데코레이터도 후보 |
| 버전 계산의 정규화 | 주석·공백만 바뀐 것은 같은 버전으로 보도록 AST 정규화를 검토 중 |
| 같은 요청이 동시에 여러 번 올 때 | 계산은 한 번, 배달은 여러 번이라는 원칙만 정함. 기록 방식의 세부는 미정 |
| 큰 데이터·스트리밍 | `ctx.load()`, `ctx.save()`의 세부 미정 |
| cold 저장소 | SQLite 파일을 하나 더 두는 방식이 유력 |
| 삭제 요청 API | 함수 이름·인자, IAM `delete` 규칙의 `target` 문법 미정 |
| Action 수집 범위 | import로 닿는 모든 파일로 할지, 함수 호출 경로로 좁힐지. 동적 import 처리 |
| 사용자 Action 격리 | 서브프로세스에서 돌리는 옵션. 첫 버전에서는 하지 않음 |
| 엔진과 서비스 사이 인증 | 로컬 단일 사용자 전제라 첫 버전에는 없음 |
| DB 구조 변경 시 자동 변환 | 0.x 동안은 없음. 1.0 전에 추가 |
| PyPI 이름 | `msdf` 사용 가능 여부 확인 전. 안 되면 `ms_dataflow`. import 이름은 어느 쪽이든 `ms_dataflow` |
